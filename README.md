# ThinkTrail

Say what a browsing session is for, press Record, and see how much of your time served that goal.

**Website and install guide:** https://sirish123.github.io/ThinkTrail-Public/

## Install

1. Download [`downloads/thinktrail-1.0.0.zip`](downloads/thinktrail-1.0.0.zip) and unzip it somewhere permanent.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and choose the unzipped folder.
4. Pin ThinkTrail in the toolbar, then press ⌘⇧K (Ctrl+Shift+K on Windows) to start a session.

Needs desktop Chrome or another Chromium browser. On-device analysis with Gemini Nano needs Chrome 138 or later and a capable machine; any chat AI works as an alternative.
